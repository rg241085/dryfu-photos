Setup baaki hai

Photo kahan save ho

Sync ke liye Cloudinary → Settings → Security → "Restricted image types" mein Resource list ka tick hatayein.

Naam / category badalna aur delete (optional)

Cloudinary → Settings → API Keys se milegi. Ye sirf isi device mein save hoti hai, GitHub par nahi jaati. ⚠️ API Secret kisi ko na dikhayein.

Dusre device (mobile / laptop) ko jodein

Mobile ke camera se QR scan kijiye ya ye link mobile par kholiye. Settings apne aap aa jayengi.

⚠️ Ye link sirf apne devices par use karein, kisi ko forward na karein.
